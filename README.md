# IMDb Movies SQL Analysis

## Project Overview
This project analyzes IMDb movie data using SQL to identify
patterns and insights related to movies and directors.

## Tools & Technologies
- SQL
- MySQL
- Database Management

## Analysis Performed
- Movie count analysis
- Director analysis
- Gender-based analysis
- Filtering using WHERE and LIKE
- Aggregation using COUNT
- GROUP BY analysis
- Sorting using ORDER BY
- JOIN operations

## SQL Concepts Used
- SELECT
- WHERE
- LIKE
- COUNT
- GROUP BY
- ORDER BY
- LIMIT
- OFFSET
- JOIN

## Project Outcome
The analysis helped identify patterns in the movie dataset
and demonstrated practical SQL querying and data analysis skills.
